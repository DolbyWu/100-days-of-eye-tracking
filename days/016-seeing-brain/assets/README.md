# Anatomical assets

This build uses one anatomical coordinate system throughout. Z-Anatomy's Blender archive supplies the bony skull with available teeth, cortical groups, cerebellum, brainstem, eyes, and named optic structures. The manifest records each original object, vertex transform, triangle count, source archive and derived SHA-256. The complete archive and untouched Blender scene remain in `raw/`. Exported OBJ coordinates are normalized scene units. No smoothing, decimation, inter-atlas warp, or left/right reflection was applied. The cortical groups combine objects in the source Neo-cortex collection and are not watertight hemisphere segmentations.

The external Brain Atlas repository has regional OBJ files and classifies its Jülich meshes as CC BY-NC-SA 4.0. Its MNI template and HCP-derived fibers have other terms. No validated subject-to-template transform was available for the Z-Anatomy head. External atlas meshes were excluded and the native named anatomy was used for landmark proxies. Brainnetome and SPINS were not incorporated. [Brain Atlas data inventory](https://github.com/brain-atlas/brain-atlas.github.io/blob/e7001c9e7fcf8c93590804e9bc45db4f7c479923/DATA_LICENSES.md)
