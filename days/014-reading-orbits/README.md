# Day 014 · Reading Orbits

Mac 摄像头拍摄读者。Neon 眼部视频变成两个始终朝向观众的圆形窗口，你把它们放在哪里，它们就停在哪里。Neon 第一视角拍下书页。视线短暂停在一个词上，词就从一只眼睛的正面喷出，沿弧线落下，再浮回它在原页上的相对位置。文字统一使用 31 点字号，从出现到归位保持原大。两只眼睛轮流出词，拖动圆形眼睛会把已经出现的词推开。

## 打开作品

双击同目录下的 **Day14-Reading-Orbits-Dashboard.toe**（带实时数据面板），也可以打开 **Day14-Reading-Orbits.toe**。作品会打开画面和 **day14_reading** 参数窗口，在 **Reading** 页操作。保留整个目录，手部与文字识别需要旁边的两个 Mac 可执行文件。

- **先体验**：打开 **Demo Book**。示例页会模拟逐词阅读，可以看见下落和归位。关闭后切回摄像头。
- **真机阅读**：启动原来的 **TD-Neon** 和 Neon Companion，让 Mac 和 Companion 连接同一局域网。当前电脑的旧版桥接使用 **9000**。如果你的桥接窗口显示 **9012**，在本工程的 **Cameras → OSC Port** 填 9012。每个端口只开一个 TouchDesigner 接收工程。
- **识别第一页**：将书页正对 Neon，光线充足，让文字占据第一视角的大部分。按 **Scan Page**。状态栏会显示记录了多少个词。翻页后再次按下即可。
- **用 OpenAI 看书页**：按 **Enter API Key**，在 Mac 的隐藏输入框粘贴 OpenAI API key。成功输入后识别器切换至 OpenAI。按 **Scan Page** 会发送一张 Neon 第一视角画面。默认的 **Apple Vision (local)** 可以直接在电脑上识字。密钥只在当前 TouchDesigner 会话内使用。
- **自动翻页识别**：可打开 **Auto Scan New Pages**。本地识字会比较连续两次采样，遇到正文或图像特征稳定的新页时触发当前识别方式。同一页可以手动重扫。选择 OpenAI 时，自动扫描也会发送新页图片并产生 API 用量。

## 用手摆放眼睛

在 Mac 摄像头前，将拇指和食指移到一个眼睛圆片内，捏住后拖动。松手停在当前位置。要缩放同一只眼睛，第一只手继续捏住，再用另一只手捏住圆片另一侧，两手拉开或靠近。两只眼睛都能分别调整，手部骨骼只参与计算。

## 读词和记录

识别完成后继续看书。系统把有效视线坐标映射回扫描图，在同一个词附近停留约 85 毫秒触发。轻微头动用书页特征对齐。丢失匹配时暂停出词，重新看向该页或重扫。相邻小字的判定会受画面清晰度、视线精度和视频延迟影响。同页内每个印刷位置出词一次，重复出现的同一个单词各自有位置。

书页词表和原图归一化位置写入本目录的 **readings/** 中，按扫描时间命名。配套 JSONL 文件记录实际触发的词及时间。示例模式不会写入阅读记录。

## 相机与连接

- **Mac 背景空白**：给 TouchDesigner 摄像头权限，在组件内的 **mac_camera** 选内置摄像头。
- **只看到示意眼睛，或提示等待书页**：在 **Cameras** 页填写 Companion 的局域网 IP。程序优先使用桥接广播的眼部地址，旧版桥接会用现有 Python 环境向 Companion 查询实际视频地址。也可以关闭相应自动选项，将桥接日志中的 **Eye RTSP** 填入 **Eye RTSP**，**Scene RTSP** 填入 **Scene RTSP**。两种视频分开使用。自动查询查找同级 Day 12、当前目录或工作区 touchdesigner 文件夹中的 .venv。
- **识别成功但没有出词**：检查桥接端口、佩戴状态和视线有效性。把头转回扫描时的角度，保持书页平整，优先用大字正文测试。
- **OpenAI 返回错误**：状态栏显示错误。检查联网、API key、账户额度和模型访问权限；也可以切回本地识别。

## 实现

已在 Apple silicon Mac 和 TouchDesigner 2023.12480 上构建。手部识别沿用 Day 13 的 Apple Vision 工具；书页本地识字和多语言字形使用 Apple Vision 与 Core Text。OpenAI 路径使用 Responses API 的图像输入，默认模型为 gpt-4.1-mini。书页和视线的匹配属于近似实时对齐。

如需重编原生工具，在此目录运行：

```sh
swiftc -O hands.swift -o day13-hands
swiftc -O PageVision.swift -o page-vision
```

从源码重建时，在空白 TouchDesigner 工程的 Textport 中加载 build_td.py，调用 build(Path(...))，传入本目录路径，然后将工程另存到同一目录。

### 图表和插图

注视图内约 0.2 秒，扫描时保存到内存的原图裁片从眼睛前方展成薄纱，收拢为清晰图片后落下，再回到书页排版中的位置。图内的坐标轴和标签随整图出现，图外的正文仍逐词喷出。打开 **Demo Book** 即可看到示例波形图。OpenAI 模式返回图表、表格、示意图和插图的区域，本地模式通过遮去已识别文字、聚合剩余边缘来估计图像范围。无边框、极淡或细节稀少的图可改用 OpenAI 重扫。

扫描会在本机将同一帧分成四个重叠区域，放大两倍并轻度锐化，再按原页坐标补入漏读的词。OpenAI 模式仍只发送一次整页图像。

**清晰底稿阅读**：在 Reading 页按 Import Photo or PDF，选择同一版书页的照片或 PDF。PDF 按文件实际页序从 1 输入页码。Apple Vision 在本机识字；选择 OpenAI 时会发送所选页的图像。看回实体书，尽量让整页入镜，待状态变成 reading 后按自然距离读。翻页后重新导入对应页；Scan Page 会切回眼镜取图。PDF 解码使用 Poppler。
